# Base Game art list

**For Elliott.** Names only. These are the **160 new pieces** the Base Game needs, grouped by the design batch they belong to. The 119 pieces of art the library reuses are already in `assets/cards` and aren't listed.

**House style and composition:** as before: portrait 5:7, the subject large in the upper 60%, the lower third calmer, no text or frames. Pokémon in their natural habitat, golden-hour painterly style.

**Order:** Batch 1 first. It completes the five Types that are already mostly drawn, so it can be built and played soonest.
